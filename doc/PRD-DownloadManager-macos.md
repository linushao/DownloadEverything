# DownloadManager macOS Target 产品需求文档

> 版本：v0.1（首次落盘日期：2026-06-02）
> 状态：草稿（Draft）

## 1. 概述

### 1.1 项目背景

当前项目为 iOS 平台的下载管理应用 **DownloadManager**，已具备完整的下载管理、M3U8 视频下载和文件管理功能。现需添加 macOS Target，实现跨平台支持，让用户可以在 macOS 上使用相同的功能。

### 1.2 产品愿景

为用户提供统一的下载管理体验，支持在 iOS 和 macOS 之间无缝切换，充分复用现有代码资产，降低维护成本。

### 1.3 术语表

- **Target**：Xcode 项目中的构建目标
- **Universal App**：支持多种架构（Intel + Apple Silicon）的应用
- **M3U8**：HTTP Live Streaming (HLS) 流媒体协议
- **TS**：MPEG Transport Stream，视频流分片格式

## 2. 用户分析

### 2.1 目标用户

- **现有 iOS 用户**：希望在 Mac 上也能使用熟悉的下载管理功能
- **新用户**：Mac 用户寻找可靠的下载管理工具

### 2.2 用户角色

| 角色 | 描述 | 需求 |
| :--- | :--- | :--- |
| 重度下载用户 | 经常下载大文件和视频 | 稳定的断点续传、批量下载管理 |
| 视频内容创作者 | 需要下载 M3U8 视频流 | 高质量视频下载和合并 |
| 普通用户 | 偶尔下载文件 | 简单易用的操作界面 |

### 2.3 用户画像

- **年龄**：18-45 岁
- **职业**：学生、上班族、内容创作者
- **设备**：Mac（Apple Silicon）
- **使用场景**：工作学习中下载资料、离线观看视频

## 3. 功能需求

### 3.1 功能总览

| 功能模块 | 状态 | 说明 |
| :--- | :--- | :--- |
| 下载管理 | 需迁移 | 文件下载、断点续传、进度显示 |
| M3U8 下载 | 需迁移 | 视频流解析、分片下载、TS 合并 |
| 文件管理 | 需迁移 | 文件浏览、预览、分享 |
| 数据持久化 | 需适配 | CoreData 数据存储 |

### 3.2 核心功能详解

#### 3.2.1 下载管理
- 支持 HTTP/HTTPS 文件下载
- 断点续传功能
- 下载进度实时显示
- 下载队列管理（暂停、继续、取消）
- 下载完成通知

#### 3.2.2 M3U8 下载
- M3U8 播放列表解析
- 分片并行下载
- TS 文件合并为完整视频
- 支持 VideoToolbox 硬件加速

#### 3.2.3 文件管理
- 下载文件列表展示
- 文件预览（图片、视频）
- 文件分享功能
- 本地文件系统交互

### 3.3 功能优先级

| 优先级 | 功能 | 说明 |
| :--- | :--- | :--- |
| P0 | 基础下载功能 | HTTP 文件下载、断点续传 |
| P0 | M3U8 下载 | 视频流下载和合并 |
| P1 | 文件管理 | 文件列表、预览、分享 |
| P2 | 高级功能 | 批量下载、定时下载等 |

## 5. 界面设计

### 5.1 信息架构

```
├── 主窗口
│   ├── 工具栏（添加下载、搜索）
│   ├── 下载列表区域
│   └── 状态栏（下载速度、数量统计）
├── 下载详情面板
│   ├── 进度条
│   ├── 文件名和大小
│   └── 操作按钮（暂停、取消）
└── 文件预览窗口
    ├── 媒体播放器/图片查看器
    └── 分享按钮
```

### 5.2 页面流程

```
启动应用 → 主界面（下载列表）→ 添加下载 → 下载中 → 完成 → 预览/分享
```

### 5.3 核心页面说明

#### 主界面
- 左侧：下载列表（进行中、已完成、失败）
- 右侧：选中任务详情或预览

#### 工具栏
- 添加下载按钮（支持 URL 输入和文件拖拽）
- 搜索框
- 筛选选项（全部、进行中、已完成）

## 7. 技术方案

### 7.1 技术选型

| 分类 | 技术 | 说明 |
| :--- | :--- | :--- |
| 语言 | Swift | 与 iOS 项目保持一致 |
| UI 框架 | SwiftUI | 跨平台支持，简化适配 |
| 数据存储 | CoreData | 复用现有数据模型 |
| 网络 | URLSession | 原生网络库 |

### 7.2 系统架构

```
┌─────────────────────────────────────────────────────┐
│                    macOS App                        │
├─────────────────────────────────────────────────────┤
│                  SwiftUI UI Layer                   │
│   (主窗口、下载列表、详情面板、预览视图)             │
├─────────────────────────────────────────────────────┤
│               DownloadAppShared (共享模块)          │
│   ├── Core: DownloadManager, M3U8Downloader        │
│   ├── Data: CoreDataManager, Repositories          │
│   ├── Network: NetworkService                      │
│   └── UI: 平台无关组件                             │
└─────────────────────────────────────────────────────┘
```

### 7.3 第三方依赖

| 依赖 | 用途 | 来源 |
| :--- | :--- | :--- |
| None | 项目无第三方依赖 | - |

### 7.4 平台适配要点

1. **资源路径适配**：macOS 与 iOS 的文件系统路径差异
2. **权限适配**：macOS 的文件访问权限机制
3. **UI 适配**：macOS 窗口布局与 iOS 布局差异
4. **后台下载**：macOS 的后台任务处理
