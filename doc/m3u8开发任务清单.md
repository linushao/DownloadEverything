## 四、技术要点

### 4.1 代码规范

- 使用面向协议的编程（参考 coding_rules.md）
- 避免魔术数字，使用常量或枚举
- 优先使用 async/await
- 使用 DispatchQueue 保证线程安全
- 新代码优先使用 Actor 模型

## 六、ffmpeg-kit 集成指导

### 在 Xcode 中添加 ffmpeg-kit Swift Package

1. 打开 Xcode 项目
2. 选中项目导航器中的项目文件 (DownloadManager.xcodeproj)
3. 选中 "DownloadManager" 项目（不是 target）
4. 点击 "Package Dependencies" 标签
5. 点击 "+" 按钮添加新的包依赖
6. 在 "Enter Package URL" 字段中输入：
   ```
   https://github.com/arthenica/ffmpeg-kit
   ```
7. 选择 "Up to Next Major Version"，版本选择 "6.0" 或更高
8. 点击 "Add Package"
9. 在 "Choose Package Products for ffmpeg-kit" 中选择：
   - `ffmpeg-kit-ios` (iOS 平台)
   - 或 `ffmpeg-kit-macos` (macOS 平台)
   - 或根据需要选择完整版本如 `ffmpeg-kit-full-gpl`
10. 点击 "Add Package" 完成集成

### 验证 ffmpeg-kit 集成

在代码中添加以下测试来验证 ffmpeg-kit 是否正常工作：

```swift
import FFmpegKit

func testFFmpeg() {
    let session = FFmpegKit.execute("-version")
    print("FFmpeg exit code: \(session.getReturnCode())")
    print("FFmpeg output: \(session.getOutput())")
}
```
