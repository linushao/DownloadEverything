# DownloadApp m3u8下载模块产品需求文档（PRD）

---

## 1. 项目背景与目标

### 1.1 背景说明

随着流媒体内容的普及，越来越多的视频资源采用m3u8格式进行分发。m3u8是Apple推行的HTTP Live Streaming（HLS）协议的核心文件格式，广泛应用于在线视频、直播回放、在线教育等场景。当前DownloadApp仅支持常规HTTP/HTTPS文件下载，无法满足用户对m3u8视频资源的下载需求。

### 1.2 产品目标

| 目标类型 | 具体目标 |
| :--- | :--- |
| **核心目标** | 新增m3u8链接解析与下载功能，支持主流HLS视频源下载 |
| **用户体验目标** | 用户体验与现有下载功能保持一致，操作简便直观 |
| **技术目标** | 复用现有下载架构，最小化代码侵入，支持后续扩展 |

### 1.3 需求范围

| 范围类型 | 具体内容 |
| :--- | :--- |
| **包含** | m3u8链接解析、TS分片下载、分片合并、进度展示、下载管理 |
| **不包含** | m3u8直播流下载（实时流）、视频解码与播放、DRM版权保护内容下载 |

## 2. 功能需求

### 2.1 核心功能

#### 2.1.1 m3u8链接解析

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| **主播放列表解析** | 解析顶层.m3u8文件，识别媒体播放列表和关键信息 | P0 |
| **媒体播放列表解析** | 解析#EXTM3U标签下的媒体片段列表 | P0 |
| **Variant Stream处理** | 支持多码率m3u8（MASTER PLAYLIST），自动选择合适码率 | P1 |
| **分片信息提取** | 提取#EXTINF标记的分片时长和URL信息 | P0 |
| **AES-128加密支持** | 支持AES-128加密的m3u8分片（提供KEY URI） | P1 |
| **相对路径处理** | 支持相对路径URL自动补全为绝对路径 | P0 |

#### 2.1.2 分片下载管理

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| **分片队列管理** | 按顺序下载TS分片，支持并发下载（默认2个分片） | P0 |
| **断点续传** | 单个分片下载中断可续传，整体任务可暂停/恢复 | P0 |
| **分片验证** | 下载完成后验证分片完整性 | P1 |
| **失败重试** | 单个分片下载失败自动重试（最多3次） | P0 |
| **速度限制** | 复用现有速度限制功能，控制分片下载速率 | P2 |

#### 2.1.3 分片合并

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| **顺序合并** | 按播放顺序拼接TS分片为单一文件 | P0 |
| **格式支持** | 输出为.mp4格式（容器转换） | P0 |
| **临时文件清理** | 下载完成后自动清理分片临时文件 | P0 |
| **进度反馈** | 合并过程中提供进度反馈 | P0 |
| **合并校验** | 合并完成后校验文件完整性 | P1 |

#### 2.1.4 下载任务管理

| 功能点 | 详细描述 | 优先级 |
| :--- | :--- | :--- |
| **任务创建** | 识别m3u8 URL自动创建下载任务 | P0 |
| **任务状态展示** | 显示解析状态、分片下载进度、合并进度 | P0 |
| **任务操作** | 支持暂停、恢复、取消、删除操作 | P0 |
| **任务队列** | 与现有下载任务共享队列，统一调度 | P0 |
| **任务记录** | 下载记录持久化到Core Data | P0 |

### 2.2 用户交互流程

```
用户输入m3u8链接
        │
        ▼
URL有效性检查
        │
        ▼
下载任务创建（状态：解析中）
        │
        ▼
获取m3u8文件内容
        │
        ▼
解析播放列表
        │
        ├──▶ 解析失败 → 任务失败，提示错误
        │
        ▼
获取分片URL列表
        │
        ▼
状态更新：开始下载分片
        │
        ▼
循环下载分片（支持并发）
        │
        ├──▶ 全部下载完成 → 进入合并流程
        │
        └──▶ 部分失败 → 重试或标记任务失败
        │
        ▼
状态更新：合并中
        │
        ▼
分片合并为MP4
        │
        ▼
状态更新：已完成
        │
        ▼
清理临时文件，通知用户
```

### 2.3 异常处理

| 异常场景 | 处理策略 |
| :--- | :--- |
| **无效URL** | 提示"链接无效或格式不支持" |
| **网络错误** | 自动重试3次，间隔2秒，仍失败则标记任务失败 |
| **m3u8解析失败** | 提示"无法解析视频源，请确认链接是否有效" |
| **分片下载失败** | 单分片重试3次，全部失败则任务失败 |
| **磁盘空间不足** | 检测到空间不足时暂停下载，提示用户 |
| **应用被终止** | 重启后从断点恢复（已下载分片保留） |
| **合并失败** | 删除已合并数据，允许用户重新下载 |

## 3. 非功能需求

### 3.1 性能要求

| 指标 | 要求 |
| :--- | :--- |
| **解析速度** | m3u8文件解析（<100个分片）不超过2秒 |
| **分片下载速度** | 与常规HTTP下载速度一致，无明显额外开销 |
| **合并速度** | 合并速度应快于下载速度，不成为瓶颈 |
| **内存占用** | 单个m3u8任务内存占用不超过100MB |
| **磁盘占用** | 临时分片存储于缓存目录，完成后及时清理 |

### 3.2 兼容性要求

| 要求项 | 说明 |
| :--- | :--- |
| **iOS版本** | 支持iOS 16.0及以上版本 |
| **macOS版本** | 支持macOS 13.0及以上版本 |
| **HLS版本** | 支持HLS Protocol Version 3、4 |
| **加密格式** | 支持AES-128-CBC加密（带URI的KEY） |

### 3.3 技术约束

| 约束项 | 说明 |
| :--- | :--- |
| **依赖库** | 优先复用现有Alamofire网络库，考虑引入ffmpeg-kit用于TS转MP4 |
| **代码侵入** | 最小化对现有DownloadManager的修改 |
| **线程安全** | 分片下载和合并操作需在后台线程执行 |
| **存储位置** | 合并后文件保存至用户指定的下载目录 |

## 4. 技术方案

### 4.1 架构设计

#### 4.1.1 模块架构

```
┌─────────────────────────────────────────────────────────────┐
│                      UI Layer                               │
│  (DownloadListView / DownloadDetailView)                    │
└─────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌─────────────────────────────────────────────────────────────┐
│                   DownloadManager                            │
│  ┌─────────────────┐    ┌─────────────────┐                 │
│  │  NormalDownload │    │   M3U8Download   │                 │
│  │     Module      │    │     Module       │                 │
│  └─────────────────┘    └─────────────────┘                 │
└─────────────────────────────────────────────────────────────┘
                              │
              ┌───────────────┼───────────────┐
              ▼               ▼               ▼
┌─────────────────┐ ┌─────────────────┐ ┌─────────────────┐
│ M3U8Parser      │ │ M3U8Downloader  │ │ TSMerger        │
│ (m3u8解析)      │ │ (分片下载)       │ │ (分片合并)       │
└─────────────────┘ └─────────────────┘ └─────────────────┘
```

#### 4.1.2 核心类设计

| 类名 | 职责 | 关键属性/方法 |
| :--- | :--- | :--- |
| **M3U8Parser** | 解析m3u8文件内容 | `parse(url:) -> M3U8Playlist` |
| **M3U8Playlist** | 封装解析后的播放列表数据 | `segments: [MediaSegment]`, `isVariantStream: Bool` |
| **MediaSegment** | 单个媒体分片信息 | `url: URL`, `duration: Double`, `sequenceNumber: Int` |
| **M3U8Downloader** | 管理m3u8下载任务 | `start()`, `pause()`, `resume()`, `cancel()` |
| **TSMerger** | 分片合并为MP4 | `merge(segments:output:progress:completion:)` |
| **M3U8DownloadTask** | 继承自DownloadTask，扩展m3u8支持 | `segments: [MediaSegment]`, `downloadedSegments: [Int]` |

### 4.2 数据结构

#### 4.2.1 M3U8Playlist

```swift
struct M3U8Playlist {
    let url: URL                          // 播放列表URL
    let isVariantStream: Bool             // 是否为多码率流
    let variants: [VariantStream]?        // 多码率变体（如果适用）
    let segments: [MediaSegment]         // 媒体分片列表
    let totalDuration: Double             // 总时长（秒）
}
```

#### 4.2.2 MediaSegment

```swift
struct MediaSegment {
    let sequenceNumber: Int               // 分片序号
    let url: URL                          // 分片完整URL
    let duration: Double                  // 分片时长（秒）
    let title: String?                    // 分片标题
    let encryptionMethod: EncryptionMethod?  // 加密方式
    let encryptionKeyURI: URL?            // 加密KEY URI
}
```

### 4.3 接口设计

#### 4.3.1 M3U8Parser接口

| 方法 | 参数 | 返回值 | 说明 |
| :--- | :--- | :--- | :--- |
| `parse` | `url: URL` | `M3U8Playlist` | 异步解析m3u8文件 |
| `parse` | `content: String, baseURL: URL` | `M3U8Playlist` | 解析m3u8内容字符串 |
| `isValidM3U8` | `url: URL` | `Bool` | 检查URL是否为有效m3u8 |

#### 4.3.2 TSMerger接口

| 方法 | 参数 | 返回值 | 说明 |
| :--- | :--- | :--- | :--- |
| `merge` | `segments: [URL], outputURL: URL, progress: (Double) -> Void` | `Result<URL, Error>` | 合并分片为MP4 |
| `cancel` | 无 | `Void` | 取消合并操作 |

## 9. 风险评估

| 风险项 | 风险等级 | 缓解策略 |
| :--- | :--- | :--- |
| **TS分片数量过多导致下载时间长** | 中 | 提供并发下载支持，显示预估剩余时间 |
| **部分m3u8使用非标准格式** | 高 | 建立格式白名单，对不支持格式提示用户 |
| **TS合并占用大量磁盘IO** | 低 | 使用后台队列合并，避免阻塞主线程 |
| **大文件合并内存溢出** | 中 | 分批读取写入，使用流式处理 |
| **加密m3u8无KEY无法下载** | 中 | 提示用户需要提供KEY URL |

## 附录

### A. m3u8格式示例

```m3u8
#EXTM3U
#EXT-X-VERSION:3
#EXT-X-TARGETDURATION:10
#EXT-X-MEDIA-SEQUENCE:0
#EXTINF:9.9,
segment0.ts
#EXTINF:9.9,
segment1.ts
#EXTINF:9.9,
segment2.ts
#EXT-X-ENDLIST
```

### B. 多码率m3u8示例（MASTER PLAYLIST）

```m3u8
#EXTM3U
#EXT-X-STREAM-INF:BANDWIDTH=1280000,RESOLUTION=720x480
medium.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=2560000,RESOLUTION=1280x720
high.m3u8
#EXT-X-STREAM-INF:BANDWIDTH=768000,RESOLUTION=320x180
low.m3u8
```

### C. 术语表

| 术语 | 说明 |
| :--- | :--- |
| HLS | HTTP Live Streaming，Apple制定的流媒体传输协议 |
| m3u8 | HLS协议使用的播放列表文件格式 |
| TS | Transport Stream，传输流文件格式 |
| MASTER PLAYLIST | 多码率播放列表，用于不同带宽的适配 |
| AES-128 | 128位高级加密标准，用于内容加密 |
| EXTINF | m3u8中的分片时长标记 |
